# QuantMind 实盘 / 模拟交易 操作指南

> 说明如何在 QuantMind 主界面进行模拟交易和实盘（通达信）交易，以及两者的区别。

---

## 一、两种交易模式

| | **模拟盘 (SIMULATION)** | **实盘 (REAL, 通达信)** |
|---|---|---|
| **撮合方式** | 本地仿真（quantdb 行情 + A股规则） | 通达信客户端真实下单 |
| **交易通道** | 无需外部依赖 | Windows 通达信桥 (:8550) |
| **下单确认** | 自动成交 | **需通达信客户端人工确认** |
| **资金** | 虚拟资金 | 真实账户资金 |
| **适用场景** | 策略验证、试运行 | 真实执行 |

---

## 二、切换交易模式

### 2.1 首页顶栏切换

打开 `http://127.0.0.1:3080`（quantmind-web）：

- 顶部 HeaderBar 有一个 **REAL/SIM 滑动开关**
- 往右切 → **实盘(通达信)**
- 往左切 → **模拟盘**

> 切换后写入 Redux 全局状态，所有交易相关页面自动跟随。

### 2.2 切换后确认

切换到实盘后，顶部会显示**实盘(通达信)** 标记。此时进入"模拟交易"页面，顶部横幅变绿色：

> **实盘(通达信)**：本页委托通过通达信交易桥下达到 Windows 通达信客户端，实盘下单需在通达信客户端手动确认。

---

## 三、模拟交易页面功能

左侧导航 → **模拟交易**，包含 7 个标签页：

| 标签 | 功能 | 说明 |
|------|------|------|
| **策略管理** | 启动/停止策略、预检 | 全自动模拟控制台 |
| **时光回放** | 历史行情回放 | 验证策略 |
| **手动任务** | 手动调仓向导 | 信号→预案→提交 |
| **持仓监控** | 当前持仓图表 | 饼图+明细 |
| **交易记录** | 委托/成交历史 | 支持导出 |
| **个人中心** | 账户设置/重置 | 模拟盘资金重置 |
| **设置** | 凭证 + 通达信桥 | token 管理 |

### 3.1 策略管理（全自动）

1. 选策略 → 点"启动"
2. 系统做预检（模型/数据/环境就绪度）
3. 通过后进入全自动执行：每天推理 → 自动下单

- **模拟盘**：下单自动虚拟成交
- **实盘**：下单推送到通达信，客户端弹确认框

### 3.2 手动任务（手动调仓）

5 步向导：
1. 选模型 + 推理批次 (run_id)
2. 选策略
3. 确认参数
4. **生成预案**（预览卖/买单 + 金额）
5. **提交执行**

> 实盘模式下提交后，通达信客户端会弹出确认框，逐单人工确认。

### 3.3 持仓监控

- 饼图显示持仓分布
- 明细表：代码/数量/可用/成本/市值
- 实盘模式显示通达信真实持仓

### 3.4 设置 → 通达信交易桥

**模拟交易 → 设置** 页底部新增"**通达信交易桥**"卡片：

```
通达信交易桥
[自动推送: 开启] [实盘: 开启] [桥: http://192.168.31.22:8550] [Token: 已配置]

桥在线 · 通达信客户端: 已连接      ← 健康状态实时显示

桥地址    [ http://192.168.31.22:8550 ]
桥 Token  [ 输入新 token (留空保持现有) ]
[保存配置]
```

## 四、实盘交易完整流程

```
┌─────────────┐    ┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│ QuantMind   │───▶│ Windows 桥    │───▶│ 通达信客户端  │───▶│ 用户确认成交  │
│ 策略推理下单 │    │ 0.0.0.0:8550 │    │ 弹确认框      │    │ 点"确认"     │
└─────────────┘    └──────────────┘    └──────────────┘    └──────────────┘
       ▲                                                   │
       └────────── 查询状态(盈亏/持仓/委托) ◀────────────────┘
```

### 4.1 前置条件（实盘必须）

1. **Windows**：桥已启动（`setup.ps1`），通达信已登录
2. **Linux**：`.env` 设 `ENABLE_REAL_TRADING=true` + `TDX_BRIDGE_TOKEN`
3. **前端**：切到实盘模式

### 4.2 下单后状态跟踪

在通达信客户端确认下单后，QuantMind 可通过 `TdxPushService` 查询：

| 委托状态码 | 含义 |
|-----------|------|
| 0 | 无效单 |
| 1 | 未成交 |
| 2 | **部分成交** |
| 3 | **全部成交** ✅ |
| 4 | 部分成交部分撤单 |
| 5 | 全部撤单 |

## 五、模拟盘特有功能

### 5.1 资金重置
个人中心 → 模拟盘 → 重置账户资金。

### 5.2 OCR 持仓同步
个人中心 → 上传通达信/券商持仓截图 → 自动识别持仓 → 同步到模拟盘。

### 5.3 模拟盘成交规则
- T+1、涨跌停、停牌、整手、佣金印花税
- 基于 quantdb 历史行情撮合

---

## 六、注意事项

1. **实盘下单必须人工确认**：通达信客户端会弹框，不点确认不成交（这是保护机制）
2. **模拟盘不会动真实资金**：SIM 模式零风险
3. **切换模式不影响已启动策略**：模式只影响"新下单"走的通道
4. **实盘需先启动 Windows 桥**：桥不在线时实盘会失败，前端会显示桥状态
5. **两端 token 一致**：Linux `.env` 和 Windows 输入的 `BRIDGE_AUTH_TOKEN` 必须相同

### 6.1 交易规则与免责声明

- **实盘（通达信）**：委托会经由通达信交易桥发送到 Windows 上的通达信客户端；每笔实盘委托仍须在客户端手动确认。开始前确认交易桥已启动，并已登录正确的交易账户。
- **模拟盘**：委托仅在本地按 quantdb 行情和 A 股规则（T+1、涨跌停、停牌、整手、佣金及印花税）撮合，不接入真实资金或券商交易通道。
- **风险提示**：模拟结果不代表真实收益，平台内容不构成投资建议。实盘交易前请自行核对策略、账户、仓位及风险承受能力。
