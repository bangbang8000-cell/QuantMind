## 摘要

本研究基于 Huntly RSS 聚合的 **42.4 万篇**历史财经新闻（2026-03-28 ~ 2026-08-20），结合 FinBERT + 金融词典双引擎情绪识别（0.6/0.4 加权融合）与股票实体提取，构建了「新闻 → 情绪信号 → 交易策略」的完整研究链路，覆盖 **51,741 个有效事件、5,661 只股票、98 个交易日**。

核心发现（v2 更新）：

1. **新闻情绪整体预测力偏弱但方向正确**：利好事件 T+5 平均 +0.15%，利空 T+5 平均 -1.10%；利空的预测力（正确率 58.7%）显著强于利好（胜率 43.2%）。
2. **新闻来源是决定信号质量的第一要素**：财联社电报预测力 +5.26% 居首；南华早报 -3.40% 为最强反向指标。来源差异高达 **8.66 个百分点**。
3. **发布时间显著影响信号有效性**：21:00 晚间消息利好 T+5 达 +1.27%（全时段最优）；凌晨 1-5 点消息 T+5 为 -1% ~ -2%（噪声）。
4. **多篇集中报道与首日动量是有效的信号过滤器**：3 篇以上集中报道的利好 T+5 收益（+0.80%）是单篇（+0.36%）的 2.2 倍。
5. **动态止盈是策略的唯一利润引擎**：trailing_stop 出场 **100% 胜率**，贡献全部正收益；固定止损全部亏损，是最大亏损源。
6. **最优策略 v3（基线）**（无止损 + 来源/时段过滤 + 多篇确认 + 首日动量 + 情绪反转出场）回测区间收益 **+84.34%**，年化 +381.67%，Calmar 比率 **7.76**。
7. **P0 升级：到期浮盈续持（v6/hw40）把收益推高到 +105.35%、Calmar 12.76**——到期日浮盈仓位不卖，继续持有到动态止盈/反转/绝对上限 40 天；浮亏仓位照常离场。「让赢家走到止盈」是出场端最后一个也是最大的利润杠杆。

### 2.2 关键结论

- **利空消息的预测力显著强于利好**：强利空 T+5 平均 -2.39%，强利好 T+5 却为 -0.17%。A 股市场对坏消息的反应又快又深，对好消息则反应迟缓（甚至不反应）。
- **利好效应衰减快**：利好的正收益集中在 T+1~T+3（+0.28%~+0.36%），T+5 之后转负。利好的最佳持有窗口是 **3 天内**。
- **利空效应持久**：利空 T+1 即 -0.44%，一路下行到 T+10 的 -1.69%，做空的最佳持有窗口可达 **10 天**。
- **T+15 之后大盘 beta 主导**：无论利好利空，T+15~T+20 均出现 -2%~-4% 的下滑，说明中长线走势由市场整体环境决定，情绪效应在两周内已耗尽。

### 5.1 多篇集中报道 vs 单篇

| 报道数 | 事件数 | 利好T+5 | 利好T+20 | 利空T+5 | 利空T+20 |
|--------|--------|---------|-----------|---------|-----------|
| 单篇 | 11,286 | +0.36% | -4.28% | -0.56% | -4.84% |
| 2篇+ | 6,582 | **+0.80%** | -4.35% | **-1.08%** | -5.79% |
| 3篇+ | 3,393 | **+0.80%** | -3.86% | **-1.02%** | -5.23% |

**多篇集中报道的利好信号强度是单篇的 2.2 倍**。媒体共振 = 共识形成，共识形成的方向更容易延续。同股票同日 ≥2 篇同向文章是可落地的信号质量过滤器。

| 3 天 | 1,596 | **+0.36%** | **40.2%** | **+0.63%** |

连续 3 天同向信号是唯一 T+5 和 T+10 均为正的组合——**持续的情绪推动比单日爆发更可信**，应给予仓位加成。

### 5.3 强信号 vs 弱信号

| 信号类型 | T+5 收益 | T+5 胜率 | T+10 收益 |
|----------|----------|----------|-----------|
| 强利好 (n=25,394) | -0.17% | 42.9% | -0.58% |

## 6. 价格行为特征

### 6.1 首日动量：消息当天涨跌的预测力

| 首日表现 | 事件数 | T+1 | T+5 | T+10 | T+20 |
|----------|--------|-----|-----|------|------|
| 首日上涨 | 31,118 | +0.36% | +0.19% | -0.31% | -4.91% |
| 首日下跌 | 20,591 | -0.22% | -0.59% | -0.86% | -1.44% |
| 首日涨>3% | 17,412 | +0.66% | **+0.58%** | -0.03% | -6.69% |
| 首日跌>3% | 6,920 | -0.30% | -0.41% | -1.52% | -3.84% |

**动量效应在 T+1~T+10 区间显著**：首日涨的继续涨，首日跌的继续跌。交叉验证：

- 利好 + 首日涨：T+5 = +0.35%（有效利好）
- 利好 + 首日跌：T+5 = -0.23%（市场不认，假利好）
- 利空 + 首日跌：T+5 = -1.40%（有效利空）
- 利空 + 首日涨：T+5 = -0.71%（利空后仍跌，但幅度减半）

**「消息方向 + 首日同向」双确认后信号质量显著提升**，这是本次研究最重要的可落地规律之一。

### 6.2 情绪反转：反向信号出现时的走势

| 止损贡献 | -107,487 | -83,044 | -53,968 |
| 动态止盈贡献 | **+71,259** | **+98,459** | **+100,593** |

三个模式的共同规律：**动态止盈赚的钱被止损全部亏掉**。做空在 2026 年下跌市中贡献显著（fade 模式夏普最高 1.03）。

### 8.2 优化参数寻优（5 个版本对比）

| 版本 | 止损 | 多篇确认 | 动量过滤 | 累计收益 | 最大回撤 | Calmar |
|------|------|---------|---------|---------|---------|--------|
| v1 严格全开 | 15% | ✓ | ✓ | +57.80% | 37.63% | 5.93 |
| v2 放宽过滤 | 20% | ✗ | ✗ | +31.41% | 60.28% | 1.69 |
| **v3 无止损（最终版）** | **禁用** | ✓ | ✓ | **+84.34%** | 49.17% | **7.76** |
| v4 中档止损 | 25% | ✓ | ✓ | +39.72% | 32.69% | 4.17 |
| v5 激进止盈 | 禁用 | ✓ | ✓ | +75.65% | 48.54% | 6.70 |

关键结论：

- **止损越宽收益越高**（15%→25%→禁用：+57.8%→+39.7%→+84.3%），新闻驱动行情「先洗盘再拉升」特征明显，固定止损系统性洗掉好仓位。
- **多篇确认 + 首日动量过滤贡献约 53 个百分点的收益**（v2 关掉后 84%→31%），是本次研究最重要的两项过滤器。
- v3 与 v5 的差异说明：动态止盈激活 15%/回撤 5% 优于激活 10%/回撤 3%（+84.3% vs +75.7%），**太敏感的止盈会过早离场**。

## 11. 风险与局限性

1. **样本期仅 5 个月**（2026-03-28 起），且整体处于下行市，结论可能过度拟合该市场环境；上涨市中的情绪传导机制可能完全不同。
2. **情绪标签存在系统性偏差**：FinBERT 对中文金融文本的微调数据有限，利空识别（58.7% 正确率）优于利好（43.2% 胜率）可能部分源于模型偏差而非市场结构。
3. **做空假设不现实**：A 股融券标的有限、成本高，回测中假设了无障碍做空。实际执行做空信号需额外过滤两融标的。
4. **回测使用收盘价成交**：盘中消息实际应在消息时刻之后成交，收盘价近似存在偏差。
5. **无止损策略的尾部风险**：回撤 49% 意味着单笔最大亏损可达 -28,013 元（-5.6% 资金），实盘需配合资金管理和心理承受能力评估。
6. **新闻源特征随时间漂移**：来源预测力排名基于历史样本，媒体风格、受众结构变化会导致信号衰减，需定期复测。
7. **v6/hw40 的续持机制风险**：（a）续持上限单调性实验基于同一 5 个月快照，60 天以上区间的"无仓位活得过"结论在更长样本期或被推翻；（b）续持期暴露于市场 beta，若大盘转熊，「让亏损仓少、盈利仓多活 40 天」的假设仍需更长窗口复验；（c）实验对比严格基于同一 PG 富集快照，跨快照对比会因富集持续更新而失真（信号数曾差 16 个）。

## 12. 结论

1. **新闻情绪信号有真实 alpha，但需要精细筛选**。原始信号接近噪声（利好 T+5 中位数 -1.05%），但叠加「来源 × 时段 × 多篇 × 首日动量」四重过滤后，信号质量大幅提升，基线策略 5 个月 +84.34%、Calmar 7.76。

2. **坏消息比好消息值钱**。利空的预测力（强利空 -2.39%）是利好（强利好 -0.17%）的 14 倍。A 股市场「利好钝化、利空敏感」的典型特征在新闻数据中清晰可见。

3. **出场机制比入场信号更决定成败**。同样一组信号，止损配置从 15% 放宽到禁用，收益从 +57.8% 提升到 +84.3%；动态止盈贡献了 100% 的正收益。**「让利润奔跑、不给亏损设硬线」是该数据分布下的最优出场哲学**。

4. **入场过滤决定信号有没有，出场机制决定利润有多少**。P0 证明：入场面（来源/时段/多篇/动量）与出场面（无止损/动态止盈/浮盈续持）可以分开优化——把 v3 的到期一刀切改成「浮盈续持」，同一批入场信号收益 **+84.34% → +105.35%**、Calmar **7.76 → 12.76**。出场是最后一块也是最便宜的利润。

5. **下一步研究建议**：
   - 将来源预测力纳入动态权重（每月滚动复测 Top-N 白名单）；
   - 引入两融标的过滤，测试可实际执行的做空版本；
   - 盘中消息按「消息时刻 + 15 分钟」分钟线价格成交，提升信号对齐精度；
   - 更长样本期（跨越上涨市）复验 hw40 续持上限的稳健性；

## 13. 从统计规律到单股深度分析：操作手册

> 前 12 章是**面**（全市场统计规律），本章是**点**（单只股票怎么用这些规律）。这是新闻情绪方法论与 [[quantdb-full-analysis-design]]（个股深分 8 层框架）的接口层——把 RSS 规律的结论落到一只股票的判断上，并与 **L2 微观结构截面**互相印证。

### 13.1 新闻面的三步纵深（个股深分 L7 层的标准动作）

对任意股票 `{code}`，新闻分析不是"有没有新闻"，而是**先直接、再相关、后规律**三步纵深：

**STEP 1 · 直接消息判定（先排除噪声）**
扫窗口 `[T-2, T]`（近 3 天）内**标题 + 正文**是否命中 `{股票名}/{code}`。
- **命中** → 逐个定性：新闻来源（白/黑名单？）、发布时段（黄金 19-22 点？凌晨噪声？）、多篇数（≥2 篇同向→信号×2.2）、当天涨跌（首日动量双确认）。
- **未命中** → 明确写「个股近期无直接催化」，**禁止用行业新闻冒充个股消息**。

**STEP 2 · 相关行业归类（板块信号衰减后注入）**
标题含 `超级电容/薄膜电容/电力设备` 等行业词的新闻，定性为"板块级、间接消息"。用板块标签（`event_tags`/`industries`）区分**利好共振**（元力量产、业绩预增）与**利空分化**（同行亏损、行业竞争加剧叙事）。

**STEP 3 · 规律对照打分（21 条规律逐条对位）**

| 规律 | 单股化判据 | 对"法拉电子 2026-08-20"命中的表现 |
|------|-----------|-------------------------------|
| 财联社利空金矿 / 同花顺利好金矿 | 有上述来源消息 → 信号加权重 | 窗口内无此类来源命中 |
| 时段黄金 19-22 点 | 消息发布于该时段 → 质量高 | 相关板块消息多为 15-18 点收盘评论 |
| 凌晨噪声过滤 | 1-5 点消息 → 直接降权 | 无 |
| 多篇≥2 同向 → ×2.2 | 同日 ≥2 篇同向 → 强信号 | 未成簇（0 篇直接） |
| 首日动量双确认 | 消息日涨>3% / 跌>3% 与情绪方向一致 | 第 11 条规律用在**利空案例**上：盘中无利空新闻却放量长阴 → 非事件驱动，属于资金面/情绪面下杀 |
| 利好→利空反转离场 | 持有中反向新闻出现 → 平仓 | 8-19~8-20 无消息→无反转信号 |
| 板块规则 | 深主板利空最深 / 创业板禁做空 | 法拉电子沪主板（利好 T+5 +0.49%，中性偏好）|
| 标签 | 事件标签（监管/业绩/增减持）出现 → 加权 | 无 |

**STEP 3 的输出形态**：一段"新闻面结论"——`个股静默（0 直接消息）→ 行业中性（超级电容利好 vs 电源板块分化）→ 无催化`。**结论永远明确，不许含糊**。

### 13.2 新闻 × L2 微观结构交叉印证（跨层，本节灵魂）

新闻面解决「**有没有催化剂**」，L2 微观结构解决「**盘里的钱在怎么动**」。两者正交，组合后覆盖事件驱动与资金驱动两类行情：

| 组合 | 含义 | 操作含义 |
|------|------|---------|
| 有直接利空新闻 + L2 负 IC 家族高位（toxicity_persistence↑ / realized_jump↑）| 事件驱动下跌，盘面确认砸盘 | 强利空，回避/做空候选 |
| 无消息 + L2 缩量阴跌（大单净流出收敛、买盘弱）| **资金惯性下行、无催化剂** | 左侧末段，仅反弹博弈，不追 |
| 有直接利好新闻 + L2 正 IC 家族扩散（vpin_vol_ratio↑、informed_ratio↑）| 消息+知情资金共振 | 高置信做多候选 |
| 有利好新闻 + L2 正 IC 家族低位（无资金跟进）| 利好不认 | 假利好/一日游，不追 |
| 无消息 + L2 vpin_vol_ratio 率先恢复 | 知情交易回归、反转前兆 | 观察确认，等第二信号 |

**阈值参考（L2 截面分位，来自《L2 微观结构因子系统化分析报告》）**：负 IC 因子 ≥70% 分位 + 正 IC 因子 ≤40% 分位 = 负面组合；反之（负≤40% / 正≥70%）= 正面组合；居中 = 中性。

### 13.3 单股深分报告中的新闻价值排序（最终）

新闻结论在整份深分报告的记忆权重（从高到低）：

1. **真实、直接、经盘面印证的催化事件**（可入库的 alpha）
2. **反向/矛盾信号的警示**（消息利好但盘面不认）
3. **噪声识别后的排除项**（增强报告可信度，本身不是信号）
4. **行业 beta 传导**（板块热度 → 个股择时背景）

> 一句话：**新闻情绪统计规律 → 个股时退化为「直接消息判定 + 相关行业归类 + 21 条规律对照」三步法；再与 L2 微观结构截面交叉，得到"催化剂 × 盘面资金"的 2×2 判断。** 此节即 [stock-market-analysis] 技能 L7 层的规范实现。
