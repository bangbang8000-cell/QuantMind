# QuantMind 选股策略 v2.0

基于 XGBoost Alpha112 模型，2024-2026年共30个月、485个交易日、300+笔交易回测验证，含参数扫描优化。

---

## 一、入场判断（三层过滤）

### 第1层：行业信号强度 — 决定是否入场

每天推理后，按申万行业分类（128个）统计 Top1 分数：

```
行业avg Top1 = (Top20中出现的各行业的Top1分数之和) / 行业数
```

**为什么用行业不用板块？** 行业有128个（细粒度），Top20分布在10-15个行业，反映"哪些行业被资金集中看好"。板块只有5个，太粗，容易被一两个大盘股拉高。

### 入场阈值（参数扫描优化结果）

| 策略风格 | 入场线 | 空仓线 | 强行业数 | 2年收益 | 最大回撤 | 胜率 | 适合谁 |
|---------|--------|--------|---------|--------|---------|------|--------|
| 保守型 | ≥0.10 | <0.10 | ≥5 | +145% | -27.6% | 64.0% | 不能承受大回撤 |
| **平衡型（推荐）** | **≥0.09** | **<0.06** | **≥2** | **+489%** | **-33.7%** | **63.5%** | **大多数人** |
| 激进型 | ≥0.07 | <0.06 | ≥1 | +559% | -35.1% | 63.5% | 能承受大回撤 |

### 为什么 entry=0.09 比 0.10 好一倍？

avgTop1 大部分时间在 0.08-0.12 之间：

| avgTop1 区间 | 天数 | 占比 | 市场状态 |
|-------------|------|------|---------|
| 0.06-0.08 | 79天 | 16.3% | 真弱，应该空仓 |
| 0.08-0.09 | 65天 | 13.4% | 弱但有机会 |
| **0.09-0.10** | **135天** | **27.8%** | **震荡，有赚钱效应** |
| 0.10-0.12 | 139天 | 28.7% | 偏强，应该入场 |
| 0.12+ | 67天 | 13.8% | 强，满仓 |

entry=0.10 意味着 57.5% 时间空仓；entry=0.09 只空仓 29.7%。多出的 28% 交易日里，强行业数2-3个，轻仓参与是赚钱的。

### 为什么 exit=0.06 比 0.08 好？

exit 越低 = 越不轻易空仓 = 多吃反弹：

| entry=0.10 + exit= | 收益 | 回撤 | 原因 |
|-------------------|------|------|------|
| exit=0.10 | +159% | -27.6% | 跌破0.10立刻空仓，太敏感 |
| exit=0.08 | +225% | -33.7% | 当前策略，给了一点缓冲 |
| exit=0.06 | +272% | -33.7% | 只有真正极弱才空仓，多参与反弹 |

回撤差异(-27.6% vs -33.7%)主要来自2024年2月微盘股崩盘，需要大盘均线过滤来弥补。

### 辅助指标：强行业数（Top1 ≥ 0.10 的行业个数）

| 强行业数/天 | 市场状态 | 操作 |
|-----------|---------|------|
| ≥ 5个 | 强势 | 满仓 |
| 3-5个 | 震荡偏强 | 半仓 |
| 2-3个 | 震荡 | 1/3仓 |
| < 1.5个 | 弱势 | 空仓 |

### 仓位管理

| 市场状态 | 行业avg Top1 | 强行业数 | 仓位 | 操作 |
|---------|-------------|---------|------|------|
| 牛市 | ≥ 0.12 | ≥ 5 | 100% | 满仓，可追强信号 |
| 震荡偏强 | 0.10-0.12 | 3-5 | 50% | 半仓，只做0.10-0.12区间 |
| 震荡 | 0.09-0.10 | 2-3 | 30% | 轻仓，快进快出 |
| 震荡偏弱 | 0.06-0.09 | 0.5-2 | 0-30% | 观望或极轻仓 |
| 熊市 | < 0.06 | < 0.5 | 0% | 绝对空仓 |

### 行业消失 = 清仓信号

如果持仓个股所属行业的 Top1 跌破入场线，说明行业优势消失，应清仓该股。

## 二、个股分数区间 — 决定买哪只

| 个股分数 | 操作 | 理由 |
|---------|------|------|
| 0.10-0.12 | **首选（黄金区间）** | 胜率64.8%，均收+1.19%，最大亏损-10.4% |
| 0.12-0.15 | 可选（主板优先） | 胜率79%但样本少，需警惕追高 |
| 0.15-0.20 | 谨慎 | 仅在强市中有效，开盘买→T+2收盘卖胜率92.8% |
| ≥ 0.20 | 极谨慎 | 趋势加速阶段，样本少 |
| < 0.10 | **不买** | 信号太弱，不可靠 |

### 为什么0.10-0.12是黄金区间？

0.12-0.14是"追高陷阱"——模型给高分往往因为股票已涨很多（动量特征强），买入容易买在山顶。0.10-0.12区间信号足够强但未过热，是最佳平衡点。

**0.10-0.11假信号区**：单独看这个区间胜率低，必须配合行业Top1 ≥ 0.09才买。

## 三、3天分数趋势 — 决定买点

| 趋势模式 | T-1→T→T+1 | 胜率 | 均收 | 操作 |
|---------|-----------|------|------|------|
| **先升后降** | 低→高→降 | **78%** | **+1.37%** | **最佳买点** |
| 连续上升 | 低→高→更高 | 62% | — | 过热，不追 |
| 连续下降 | 高→降→降 | — | — | 信号衰退，不买 |

**反直觉：分数下降比上升好。** T+1分数下降的股票次日收益+1.0%，胜率69%；T+1分数上升的股票次日收益-0.16%，胜率58%。原因：从高位回落说明绝对分数仍高，连续上升说明过热。

**大盘趋势修正**：市场连续上涨时"连续上升"趋势可追（3-4天+4%），震荡市只做"先升后降"（1-2天快进快出）。

### 每日选股3步法

1. 看今天vs昨天分数 → 今天升了=趋势好
2. 看明天预测分数 → 明天降=先升后降=买点
3. 筛选：分数0.10-0.12 + 主板(600/000) + 排名前50

| 规则 | 说明 |

## 五、买卖时机

### 买入

- **时间**：T+1日开盘（9:25集合竞价），比收盘买多赚0.3%
- **前提**：T日推理信号确认，行业avg Top1 ≥ 0.09
- **选股**：从Top50中选个股分数0.10-0.12 + 主板优先 + 先升后降趋势
- **分散**：每天选3-5只，不要单吊一只

### 卖出

- **时间**：收盘卖，比开盘卖多0.8-1.5%
- **持有期**：2-4天最优
  - 4天是甜点：均收+2.92%，胜率80.6%
  - 5天开始下降，6天以上亏钱
- **最长持有**：5天

### 止盈止损

| 组合 | 止盈 | 止损 | 最长持有 | 均收 | 胜率 |
|------|------|------|---------|------|------|
| 黄金组合（先升后降+0.10-0.12+主板） | 8% | 5% | 5天 | +6.57% | 96.1% |
| 稳健版 | 5% | 5% | 5天 | — | 98% |

**注意**：跌停板无法卖出，实际止损可能超过5%。2024年2月微盘股崩盘期间，31笔交易亏损超过5%止损线，最大-24.5%。

## 六、系统性风险过滤 — 防崩盘

### 问题

模型在暴跌时给高分（反向信号）——跌得越狠分数越高。2024年2月初avgTop1飙到0.27、强行业115个，策略满仓买入后遭遇连续跌停，回撤-29%。

### 解决方案：大盘均线过滤

当大盘指数跌破20日均线时，**强制空仓**，不管模型给多高分：

```
if 上证指数 < MA20(上证指数):
    强制空仓，不买入
```

这个规则可以避开2024年2月崩盘（上证1月底跌破20日均线），代价是可能错过部分反弹行情。

## 七、行业轮动 — 决定买什么方向

### 实时判断

每天推理后，看哪些行业 Top1 ≥ 0.10 出现天数最多，就是当前主线。

### 历史轮动规律

**2024年**：弱市(1月) → 微盘股崩盘(2月) → 反弹(3-5月) → 弱市(6月) → 制造消费(7月) → 空仓(8-9月) → 爆发(10-11月) → 弱市(12月)

**2025年**：高端制造(1月) → 消费基建(2-3月) → 科技爆发(4月) → 制造消费(5月) → 弱市(6月) → 防御公用(7-8月) → 弱市(9月) → 房地产链(10-11月) → 弱市(12月)

**2026年**：制造环保(1月) → 极弱(2-4月) → 光学光电启动(5月) → 光电+科技(6月) → 空仓(7月底-8月)

### 轮动规律

1. **小盘先动** → 成长股(科创/创业板)跟上 → 主板最后补涨
2. **行业信号持续 ≥ 3天** = 真正的轮动，不是一日游
3. **新行业出现Top1 ≥ 0.10** = 资金在切换方向，关注
4. **强行业数 ≥ 3个/天** = 有行情可做；**≤ 1.5个/天** = 应该空仓

## 八、每日操作流程

```
1. 推理完成 → 获取今日所有股票分数

2. 检查大盘均线
   - 上证指数 < MA20 → 强制空仓，结束
   - 上证指数 ≥ MA20 → 继续

3. 计算行业信号
   - 统计各行业 Top1 分数
   - 计算行业avg Top1
   - 统计强行业数（Top1 ≥ 0.10的行业个数）

4. 判断市场状态
   - 行业avg Top1 < 0.06 → 绝对空仓，结束
   - 行业avg Top1 0.06-0.09 → 观望/极轻仓
   - 行业avg Top1 ≥ 0.09 → 正常选股

5. 选股
   - 从Top50中筛选：个股分数0.10-0.12 + 主板优先
   - 检查3天趋势：优先"先升后降"
   - 排除：科创板高分、涨停板、ST股、北交所
   - 选3-5只分散

6. 检查持仓
   - 持有超过5天 → 收盘卖出
   - 所属行业Top1跌破入场线 → 清仓
   - 触发止盈8%或止损5% → 卖出（跌停除外）
   - 大盘跌破MA20 → 全部清仓

7. 下单
   - T+1开盘买入
   - 收盘卖出
```

## 十、避坑清单

| 坑 | 规则 |
|----|------|
| 追高分 | 个股分数0.12-0.14是死亡区，0胜率，均亏-12% |
| 科创板高分 | 科创板分数>0.15胜率仅47% |
| 连续上升 | T-1→T→T+1分数连续上升=过热，不追（强市除外） |
| 弱市硬做 | 行业avg Top1 < 0.06时空仓，不赌 |
| 假信号区 | 个股0.10-0.11必须配合行业确认（avgTop1≥0.09） |
| 开盘卖出 | 收盘卖全面优于开盘卖 |
| 持有太久 | 5天开始下降，6天以上亏钱 |
| 单吊一只 | 每天选3-5只分散，避免单只爆雷 |
| 崩盘追高 | 模型暴跌时给高分是反向信号，必须用大盘均线过滤 |
| 跌停卖不出 | 止损5%在跌停时无法执行，实际亏损可能远超5% |
