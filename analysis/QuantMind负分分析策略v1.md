# QuantMind 负分分析策略 v1.0

基于 XGBoost Alpha112 模型的**负分数分析**，与 `QuantMind选股策略v2.md`（正分分析）互为镜像。正分管**进攻**（选股），负分管**防守**（排雷 + 风控 + 情绪测量 + 行业流出 + 做空参考）。

**核心实证发现（2024-2026年，612个交易日，328万条全市场分数记录，已回测验证）：**

> **每日最负20只（模型最强看空）→ T+5平均收益 -4.04%（做空视角 +4.04%），下跌概率68.6%**
> 跨年稳定：2024年 -4.94%，2025年 -3.63%，2026年 -3.06%
>
> **负分占比>60%时市场T+5等权收益 -0.84%；过滤后+0.43%（情绪过滤核心应用）**
> **持仓股跌入最负Top20 → 其后5日均收 -2.56%（强清仓信号）**
> **市值是负分反弹的决定性变量：超大盘负分+1.15%、微盘负分-0.76%**
> **科创板负分抗跌：[-0.10,-0.06)区间负分T+5均收 +0.54%（负分也涨）**

负分极值的预测力明显强于正分极值——符合量化交易中"**利空比利多更有效**"的经典不对称现象。**负分极值是有分析价值的。**

## 一、排雷避坑（核心）

### 负分极值 = 最强看空信号

| 分数区间 | T+5均收 | 中位数 | 胜率 | 定性 |
|---------|---------|--------|------|------|
| **[-0.30, -0.15)** | **-2.19%** | -4.48% | 36.3% | **危险区**，坚决回避 |
| **[-0.15, -0.10)** | **-0.08%** | -1.85% | 42.6% | **临界区**，警惕 |
| [-0.10, -0.08) | +0.01% | -1.32% | 43.9% | 近中性 |
| [-0.08, -0.06) | +0.15% | -0.98% | 44.8% | 近中性 |
| [-0.06, -0.04) | +0.07% | -0.85% | 45.0% | 近中性 |
| [-0.04, -0.02) | -0.17% | -0.78% | 44.5% | 近中性 |
| [-0.02, +0.00) | -0.36% | -0.80% | 43.7% | **假信号区**，无信息 |

**关键结论：负分要"极端"才有排雷价值。**

- 每日**最负Top20**（约 ≤ -0.09 以下）→ T+5 均收 -3.06%，是可靠的危险清单
- 轻度负分（[-0.02, -0.10)）平均收益接近 0，**没有排雷价值**，是"假信号区"
- 类似正分的"0.10-0.12 黄金区间"，负分同样存在**有效区间的边界效应**，只是方向相反

### 每日排雷清单

```
1. 推理完成 → 取全市场分数
2. 筛选负分 → 取每日最负Top20（信号强度：分数 ≤ -0.08）
3. 生成"危险清单"：股票代码 + 分数 + 所属行业 + 板块
4. 操作：
   - 空仓选股时：危险清单里的股票一律不买
   - 已持仓：进入清单 → 触发清仓风控（见第二章）
```

### 为什么用最负Top20 而不用固定阈值？

| 方式 | 优点 | 缺点 |
|------|------|------|
| **固定阈值（≤-0.08）** | 信号绝对强度一致 | 弱市负分股票多，清单可能过长 |
| **每日最负Top20（推荐）** | 每日样本固定，稳定 | 强市可能没有真正危险的股票，Top20全是轻负分 |

建议**两者结合**：每日取 `最负Top20 ∩ (分数 ≤ -0.06)` 的交集作为确定性排雷清单。

## 二、持仓风控信号

正分趋势（先升后降）决定**买点**；负分趋势（转负/负加深）决定**卖点**。

### 清仓信号触发条件（满足其一即卖出）

| 信号 | 触发条件 | 逻辑 |
|------|---------|------|
| **转负信号** | 持仓股 fusion_score 从正转负，且连续2日 | 模型态度反转 |
| **极负信号** | 持仓股进入每日最负Top20 | 模型最强看空 |
| **负加深** | 持仓股分数连续2天下降且已为负 | 看空情绪加剧 |
| **行业恶化** | 持仓股所属行业平均负分进入全行业Top10最负 | 板块性资金撤离 |

### 与现有止损的关系

| 维度 | 现有止损（v2） | 负分风控（新增） |
|------|---------------|-----------------|
| 依据 | 价格（-5%） | **模型信号（转负/极负）** |
| 触发时点 | 跌了才知道 | **跌之前提前预警** |
| 互补性 | 止跌缓跌 | 抓拐点，防踩踏 |

**负分风控的价值在于领先性**：模型给的负分先于价格下跌出现，可在止损线被击穿前主动退出。两者叠加：
- 价格止损：被动兜底
- 负分风控：主动预警

## 三、市场情绪指标（负分视角）

正分 avgTop1 衡量"被看好程度"，负分衡量"被看空程度"。两者结合可识别**分化市**。

### 情绪指标定义

| 指标 | 计算 | 含义 |
|------|------|------|
| **负分占比** | 每日 fusion_score<0 的股票数 / 总数 | 看空广度 |
| **负分均值** | 全市场每日负分股票的平均分 | 看空深度 |
| **最负Top20均值** | 每日最负20只的平均分 | 恐慌程度 |
| **负分/正分比** | 负分股票数 / 正分股票数 | 空多力量对比 |

### 市场状态判读（已用回测验证）

| 负分占比 | 负分均值 | 市场状态 | 市场T+5等权均收 | 操作 |
|---------|---------|---------|----------------|------|
| < 45% | > -0.03 | 偏强 | +2.19%（<50%） | 正常选股 |
| 45-55% | -0.03 ~ -0.05 | 中性 | +0.08% | 正常，轻仓参与 |
| 55-60% | -0.05 ~ -0.07 | 偏弱 | +0.08% | 谨慎，降低仓位 |
| **> 60%** | **< -0.07** | **弱市** | **-0.84%** | **降仓或空仓**（配合正分avgTop1确认） |

**实证**：负分占比>60% 共49天，市场T+5等权均收 -0.84%；过滤后（仅≤60%参与）均收 +0.43%，全期不过滤 -0.084%。相关性 -0.267。

### 分化市识别（负分的独特价值）

```
正分avgTop1 ≥ 0.09（表面偏强）
但 负分占比 > 55%（大量股票在被看空）
→ 少数股票撑起指数，多数在跌 = 分化市
→ 操作：减仓、只做强行业龙头、不追高
```

这是正分分析**无法单独识别**的：正分只看头部，负分看到全貌。

## 四、行业流出预警（资金撤离地图）

正分行业分析（v2第七章）回答"资金往哪去"；负分行业分析回答"**资金从哪撤**"。

### 行业流出指标

| 指标 | 计算 | 含义 |
|------|------|------|
| 行业平均负分 | 行业内所有负分股票的均值 | 行业看空深度 |
| 行业负分占比 | 行业内负分股票数 / 行业股票数 | 行业看空广度 |
| 行业最负Top20出镜率 | 该行业进入每日最负Top20的次数 | 行业被集中做空程度 |

### 行业流出规则

1. **行业平均负分 Top10** = 资金撤离最重的行业，持仓应回避
2. **行业连续3天进入最负Top10** = 板块性资金撤离，清仓该行业个股
3. **行业出镜率突然上升**（如从0升至3天/周） = 资金开始撤离，预警
4. 与正分轮动表对照：行业在正分轮动表中走弱 + 负分排名升高 = 双重确认离场

### 示例（2026.07 弱市期）

弱市期（负分占比>55%）时，重灾区行业通常是：房地产开发、基础建设、综合类等——与正分 v2 中"2-4月极弱"的行业重合。

## 五、做空信号研究（参考，非实盘建议）

> ⚠️ **重要说明**：A股融券做空受限、成本高，本文档的做空研究仅作**信号有效性验证**，不作为实盘操作依据。实际应用建议优先用于：①排雷（不买）②持仓对冲（股指期货/期权对冲空头行业）③融券标的池筛选。

### 做空信号有效性（跨年实证 2024-2026，最负Top20做空）

| 持有期 | 做空收益 | 下跌概率 | 最差单笔 |
|--------|---------|---------|---------|
| 1天 | +1.13% | 59.9% | -27.5% |
| 2天 | +2.07% | 63.5% | -58.4% |
| 3天 | +2.85% | 65.7% | -72.6% |
| **5天** | **+4.04%** | 68.6% | -137.3% |
| **10天** | **+5.70%** | 71.9% | -209.3% |

**跨年一致性（做空收益单调稳定）**：

| 年度 | 持有5天做空 | 持有10天做空 | 下跌概率(5天) |
|------|-----------|------------|--------------|
| 2024 | +4.94% | +6.85% | 71% |
| 2025 | +3.63% | +4.74% | 68% |
| 2026 | +3.06% | +5.32% | 64% |

**结论**：最负Top20做空信号跨三年稳定为正收益，2024年最强、2026年最弱但仍有效。持有期越长做空收益越高（10天最优）。

### 做空信号细分：板块维度（持有5天）

| 板块 | 做空收益 | 下跌概率 | 收益std |
|------|---------|---------|---------|
| 沪主板 | **+4.97%** | 68.8% | 15.5% |
| 深主板 | +4.71% | 69.2% | 15.2% |
| 创业板 | +3.35% | 68.5% | 15.3% |
| 科创板 | +1.30% | 64.0% | 15.0% |
| ST股 | **+5.66%** | 71.8% | — |
| 非ST | +3.92% | 68.4% | — |

**结论**：主板负分做空价值最高（+4.97%），**科创板负分做空价值最低（+1.30%）**——科创板负分下跌动能弱。ST股负分下跌概率更高，但需注意退市风险与流动性。

### 做空注意事项（结合A股市场特征）

1. **最负Top20的均收是"平均值"**，个别股票可能因基本面反转大幅反弹（31.1%会上涨，均收+13.2%），需严格止损
2. **微盘股负分做空最有效但风险最高**（极端负分微盘-4.47%），但易被逼空、流动性差
3. **负分Top20常含问题股**（ST、退市风险），注意：*ST 股票无做空价值，直接排除
4. **行业集中度**：若最负Top20集中在单一行业，说明是行业性利空而非个股问题，做空需谨慎（可能被行业政策反转打脸）
5. **做空持有期越长收益越高**（10天 +5.70%），但最差单笔亏损也随持有期放大（-209%），必须止损

### 对冲应用（更实际的用法）

- 持有某行业多头时，若该行业进入负分Top10流出榜 → 用股指期货或行业ETF期权对冲
- 全市场负分占比 > 60% → 增加对冲比例（类似正分的强制空仓规则，但更灵活）
- **做空优先选主板/微盘负分股**（下跌动能最强），**避开科创板负分**（抗跌）

## 五·二、负分中也会涨的子集（做空避坑 + 逆向关注）

**用户核心关注点**：负分不全是下跌信号，有些负分股票会涨。跨年数据显示负分整体有44.9%会上涨，需要识别哪些负分值得警惕、哪些负分反而抗跌/会涨。

### 关键规律1：市值是决定负分反弹的第一变量

| 市值分桶 | 负分T+5均收 | 上涨比例 | 极端负分(< -0.15)均收 |
|---------|------------|---------|----------------------|
| **超大盘(>1000亿)** | **+1.15%** | **51.2%** | +0.80% |
| **大盘(300-1000亿)** | **+0.62%** | 48.2% | +0.66% |
| 中盘(100-300亿) | +0.29% | 46.7% | -0.54% |
| 小盘(30-100亿) | -0.29% | 44.3% | -2.27% |
| 微盘(<30亿) | -0.76% | 42.3% | **-4.47%** |

**结论**：**市值越大，负分越抗跌甚至上涨**。超大盘负分过半数会上涨（51.2%），极端负分的大盘股也正收益。而微盘股负分是重灾区（极端负分-4.47%）。做空应聚焦小市值，回避大市值。

### 关键规律2：科创板负分整体抗跌

| 板块 | 负分T+5均收 | 上涨比例 |
|------|------------|---------|
| 科创板 | **+0.28%** | 45.8% |
| 创业板 | -0.13% | 44.9% |
| 深主板 | -0.27% | 44.9% |
| 沪主板 | -0.27% | 44.7% |
| 北交所 | -0.16% | 42.6% |

科创板负分细分区间（[+区间]为正收益的）：

| 科创板负分区间 | T+5均收 | 上涨比例 |
|--------------|---------|---------|
| [-0.15,-0.10) | **+0.41%** | 44.0% |
| [-0.10,-0.08) | **+0.54%** | 45.8% |
| [-0.08,-0.06) | **+0.57%** | 46.2% |
| [-0.06,-0.04) | **+0.51%** | 46.4% |
| [-0.15,-0.31)极端 | -1.06% | 37.6% |

**结论**：科创板中轻度负分（[-0.15,-0.06)）**不跌反涨**，极端负分跌幅也远小于主板（-1.06% vs 主板-2.9~-3.3%）。科创板负分做空价值最低，应避免做空科创板。

### 关键规律3：行业负分反弹率差异

**负分反弹率最高（负分也抗跌/会涨，做空需谨慎）**：

| 行业 | 负分均收 | 上涨比例 |
|------|---------|---------|
| 全国性银行 | +0.52% | **58.6%** |
| 地方性银行 | +0.52% | 53.6% |
| 元器件 | +1.06% | 50.5% |
| 电子化学品 | +0.99% | 50.6% |
| 贵金属 | +0.52% | 48.5% |
| 半导体 | +0.81% | 48.3% |

**负分下跌率最高（负分做空最有效）**：

| 行业 | 负分均收 | 上涨比例 |
|------|---------|---------|
| 酒店餐饮 | -1.30% | 39.4% |
| 渔业 | -1.31% | 41.3% |
| 焦炭加工 | -1.18% | 39.5% |
| 医疗美容 | -1.13% | 40.6% |
| 广播电视 | -0.88% | 39.5% |
| 酿酒 | -0.71% | 40.0% |

**结论**：金融（银行）、科技成长（半导体/元器件）负分抗跌——这些板块负分往往是短期错杀；而消费服务（酒店餐饮/渔业/医疗美容）、传统周期（焦炭/酿酒）负分下跌持续性强，是做空的更好标的。

### 关键规律4：最负Top20中的反弹者长什么样

最负Top20中 31.1% 会反弹（T+5上涨），反弹者均收 +13.2%：

- 板块：创业板(1724)、深主板(1097)、沪主板(814)、科创板(139)
- ST占比仅6%（非ST反弹者为主）
- 反弹主力行业：软件服务、通用设备、专用设备、半导体

**做空风险提示**：这31%的反弹者如果做空会大幅亏损（均收+13.2%），必须用止损保护。

### 负分"可做空/应回避"决策表（综合市值+板块）

| 组合 | 负分T+5均收 | 做空价值 | 建议 |
|------|------------|---------|------|
| 微盘 + 主板 | -0.76% ~ -0.27% | **高** | 做空首选 |
| 微盘 + 极端负分 | -4.47% | **极高** | 回避/做空 |
| 大盘 + 任意 | +0.62% ~ +1.15% | 负 | **不跌反涨，做多关注** |
| 科创板 + 中轻度负分 | +0.41% ~ +0.57% | 负 | **抗跌，可关注** |
| 银行 + 负分 | +0.52% | 负 | **错杀，逆向做多** |
| 消费服务 + 负分 | -1.1% ~ -1.3% | **高** | 做空/回避 |

## 六、回测验证结果（2026.01-08 单年 + 2024-2026 跨年）

### 1. 避雷增益 — 增益有限，但结论重要

| 指标 | 数值 |
|------|------|
| Top50正分中"近5天曾进最负Top20"占比 | **0.2%** |
| 排除前 T+5 均收 | +0.207% |
| 排除后 T+5 均收 | +0.207%（无变化） |

**结论**：模型正负分切换极快，"昨日最差、今日最好"的股票几乎不存在（仅0.2%）。正负分信号**高度稳定**——一旦被标为最负，短期内难以翻身。排雷的实战价值不在于"过滤同日Top50"，而在于**长期追踪**：曾进最负Top20的股票，应列入黑名单观察。

### 2. 情绪过滤 — 最强增益（核心应用）

| 指标 | 数值 |
|------|------|
| 负分占比>60%的天数 | 49天（占总交易日38.6%） |
| **不过滤**（全期参与）T+5 均收 | **-0.084%** |
| **过滤后**（负分占比≤60%才买）T+5 均收 | **+0.43%** |
| 负分占比 vs 市场T+5 相关性 | **-0.267** |

**结论**：负分占比是有效的市场状态过滤指标。负分占比 > 60% 时市场 T+5 等权收益 -0.84%，占比 < 50% 时 +2.19%。与正分 avgTop1 叠加使用，可显著降低弱市参与度。

| 负分占比 | 天数 | 市场T+5等权均收 | 操作 |
|---------|------|----------------|------|
| < 50% | 12天 | **+2.19%** | 正常参与 |
| 50-55% | 16天 | +0.08% | 轻仓 |
| 55-60% | 44天 | +0.08% | 谨慎 |
| **> 60%** | **49天** | **-0.84%** | **空仓/降仓** |

### 3. 持仓风控 — 预警价值确认

| 指标 | 数值 |
|------|------|
| Top50买入后5日内跌入最负Top20 | 0.2%（12样本） |
| 跌入者·跌入后次日卖出均收 | -1.10% |
| 跌入者·持有5日均收 | **-2.56%** |
| 未跌入者·持有5日均收 | -0.15% |

**结论**：虽然跌入率低（模型正分稳定），但一旦持仓股跌入最负Top20，其后5日均收 -2.56%（比未跌入者差2.4个百分点）。**跌入最负Top20 = 强清仓信号**，应执行。

### 4. 做空信号 — 持有期扫描（参考）

|--------|---------|---------|---------|

| **5天** | **+3.06%** | 64.3% | -28.1% |

**结论**：做空收益随持有期单调上升，10天最优（+5.32%）。但最差单笔亏损达-39%（负分股反弹），做空必须严设止损，仅选流动性好的标的。

## 七、每日操作流程（负分模块并入）

```
1. 推理完成 → 全市场分数
2. 大盘均线过滤（同v2）
3. 计算负分情绪指标：
   - 负分占比、负分均值、最负Top20均值
   - 负分占比 > 60% → 降仓/空仓
   - 正分高 + 负分占比 > 55% → 分化市，减仓
4. 生成排雷清单（每日最负Top20 ∩ 分数≤-0.06）
   - 微盘+极端负分 → 最高优先回避/做空
   - 大盘/科创板负分 → 可能错杀，反向关注
5. 行业流出检查：
   - 行业平均负分 Top10 → 该行业持仓清仓
   - 消费服务(酒店餐饮/渔业/医疗美容)/焦炭/酿酒负分 → 做空价值高
   - 银行/半导体/元器件负分 → 抗跌，避免做空
6. 持仓检查：
   - 持仓转负/连续负加深/进入最负Top20 → 卖出
7. 选股（正分v2流程）→ 从Top50排除排雷清单中的股票
8. 下单
```

**跨年操作要点（2024-2026实证）**：
- 排雷清单按市值排序：微盘负分最危险（-4.47%），大盘负分可能反弹（+0.66%）
- 科创板负分不做空（下跌动能弱），主板/微盘负分做空首选
- 持仓股若为大盘/银行股出现负分，不必恐慌（错杀概率高）

## 八、与正分v2的对照总结

| 维度 | 正分v2（进攻） | 负分v1（防守） |
|------|--------------|--------------|
| 核心信号 | 个股分数0.10-0.12 | 最负Top20（≤-0.06） |
| 功能 | 决定买什么 | 决定不买什么/卖什么 |
| 行业视角 | 行业avgTop1≥0.09 入场 | 行业平均负分Top10 回避 |
| 市场状态 | avgTop1 判断强弱 | 负分占比判断看空广度 |
| 独特价值 | 抓住上涨 | 识别分化市、提前预警 |
| 趋势用法 | 先升后降=买点 | 转负/负加深=卖点 |
| 极端用法 | 高分追高陷阱 | 极负=强看空(跨年-4.04%) |
| 市值洞察 | 大盘股高分更稳 | **大盘负分反涨(+0.62%)，微盘负分重灾(-0.76%)** |
| 板块洞察 | 主板优先 | **科创板负分抗跌(+0.28%)，主板负分下跌强** |

**一体两面**：正分告诉你"市场在奖励谁"，负分告诉你"市场在惩罚谁"。同时看两者，才能看到完整市场。

## 附：数据验证脚本（已跑通）

快速验证负分信号有效性：

```python
import json, glob, pickle, pandas as pd, numpy as np

all_scores = {}
for f in sorted(glob.glob('top20_tracking/*_inference.json')):
    with open(f) as fh: d = json.load(fh)
    for date, rows in d.items():
        all_scores[date] = pd.DataFrame(rows, columns=['symbol','score'])

with open('top20_tracking/price_lookup_full_v2.pkl','rb') as fh:
    price = pickle.load(fh)
price_dates = sorted(set(ts for _, ts in price.keys()))
def get_close(sym, ts):
    r = price.get((sym, ts)); return r['close'] if r else None

# 最负20 vs 最正20 → T+5收益
for date, day in all_scores.items():
    day = day.dropna(subset=['score'])
    if len(day) < 100: continue
    dts = pd.Timestamp(date)
    futs = [x for x in price_dates if x > dts]
    if len(futs) < 5: continue
    for label, grp in [('最负', day.nsmallest(20,'score')), ('最正', day.nlargest(20,'score'))]:
        rets = []
        for _, r in grp.iterrows():
            c0 = get_close(r['symbol'], dts); c5 = get_close(r['symbol'], futs[4])
            if c0 and c5 and c0>0: rets.append((c5-c0)/c0)
        print(label, np.mean(rets)*100 if rets else None)
```
