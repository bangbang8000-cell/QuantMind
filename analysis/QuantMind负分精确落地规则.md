# QuantMind 负分分析 · 精确落地规则（分数范围 + 概率）

> 基于 2024-2026 跨年数据（612 交易日、146 万条负分记录）的**精确决策矩阵**。
> 所有概率为 T+5 收益统计，样本量均在 200+（多数 1000+）。
> 数据来源：`negative_score_analysis/cross_year/decision_matrix_*.csv`、`threshold_scan.csv`

## 五、一页纸落地规则（操作版）

### 做空/回避清单（按优先级）

```
1. 微盘(<30亿) + 分数 ≤ -0.20     → 下跌72%，坚决回避/做空
2. 微盘 + 分数 ≤ -0.15             → 下跌68.6%，回避
3. 小盘 + 分数 ≤ -0.20             → 下跌65.5%，回避/做空
4. 中盘 + 分数 ≤ -0.17             → 下跌60.4%，回避
5. 任何市值 + 分数 ≤ -0.23         → 下跌69-77%，极端危险
```

### 绝不回避/可关注清单

```
1. 大盘(>300亿) + 任何负分          → 均收为正，不跌
2. 超大盘(>1000亿) + 负分-0.13~-0.14 → 上涨概率56.8%，关注
3. 科创板 + 负分-0.06~-0.15         → 均收+0.3~0.8%，抗跌
4. 任何市值 + 轻负分(>-0.06)        → 中性，无做空价值
```

### 警戒线

```
- 大盘/超大盘分数 < -0.22           → 也崩（上涨概率<35%），需回避
- 轻负分 [-0.06, 0) 全市场          → 均收接近0（+0.02~0.07%），无信息
```
