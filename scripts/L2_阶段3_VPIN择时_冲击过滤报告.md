# L2 阶段3：VPIN择时 + 冲击成本过滤 信号可行性报告

> **模型**：L2 CatBoost T+5（ac5c5b2e）· **周期**：2026-01-07 ~ 2026-08-19
> **VPIN择时**：全市场 micro_vpin_vol_ratio z-score>1.5 减仓
> **冲击过滤**：micro_amihud_illiquidity 分5组看高冲击股次日收益

---

## 3a VPIN 大盘择时 — ❌ 信号方向反转，不可用

- VPIN toxic（知情交易活跃）天数：**14/151 (9.3%)**
- toxic 天**次日上证均收益 +0.260%**，非 toxic 天 **-0.043%**
- toxic 天次日下跌占比 **29%**，非 toxic 天 **46%**

**结论**：VPIN 飙升**不是下跌预警，反而次日偏涨**。
VPIN 是**正向信号**（阶段1 ICIR 0.562，IC>0）——知情交易活跃 = 资金在进场，不是撤退。
用 VPIN 做「减仓择时」会**反向操作**：在该持有的日子空仓。
这与阶段1发现一致：L2 因子是持续正向 alpha，不是风险信号。

---

## 3b 冲击成本选股过滤 — ⚠️ 信号太弱，非单调

**冲击成本（micro_amihud_illiquidity）分5组次日收益**：

| 分组 | 次日均收益 |
|---|---:|
| Q0（低冲击） | -0.004% |
| Q1（中冲击） | -0.026% |
| Q2（中冲击） | -0.037% |
| Q3（中冲击） | -0.022% |
| Q4（高冲击） | -0.022% |

- 低冲击(Q0) -0.004% vs 高冲击(Q4) -0.022%
- 差距仅 -0.018%/天，且**非单调**（Q2 最低 -0.037%）

**结论**：高冲击股次日收益略低，但差距太小（0.02%/天级）且不单调，
不构成稳定的过滤策略。剔除高冲击股可能漏掉部分流动性恢复的高收益票。

## 阶段3 总结论

1. **VPIN 择时（3a）不可行**：信号方向与择时假设相反，VPIN 是正向 alpha 不是风险信号
2. **冲击过滤（3b）价值有限**：信号弱且非单调，不构成稳定策略
3. **L2 因子的正确用法是选股 alpha，不是择时/执行/风控**——
   它们作为正向选股因子（T+5 horizon）直接进模型已经是最优用法（阶段2验证）
4. 若要进一步榨取 L2 价值，方向应是：重训用阶段1筛出的14个推荐因子（更精炼），
   而非用作择时/执行层
